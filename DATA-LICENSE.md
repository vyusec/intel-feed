# Intelligence data licenses

Original Zoli intelligence records and Zoli-authored sanitized evidence are licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/legalcode).

Attribute Zoli and retain the record's source references, revision information and correction or withdrawal status when redistributing it. This license applies only to material Zoli contributors can license.

Imported OpenSSF data retains Apache-2.0 attribution. Imported GitHub Advisory Database data retains CC-BY-4.0 attribution. Other submitted material retains its explicitly recorded source license. The `sources` field is authoritative for source-specific attribution; the feed manifest does not relicense imported text.

Package archives and third-party source code are not covered by this data license and are not distributed as part of the public feed.
